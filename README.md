# AYYY — ваш маяк в интернете

Статический портал: 18 сервисов, акварельная главная, каталог, динамическая погода с маяком и корпоративные инструменты.
Работает на GitHub Pages, без серверного приложения и без npm-сборки.

## Запуск и сборка

```sh
python src/build.py
python -m http.server 8000
```

Откройте `http://localhost:8000/`. Погода: `#weather`; независимый вход: `weather/`.

Готовый корневой `index.html` использует локальные CSS/JS из `src/`, снабжённые хешами для обновления кэша.
Модули погоды загружаются только при открытии её страницы. При публикации из `main` нужны
`index.html`, `.nojekyll`, `src/`, `assets/`, `weather/` и `tools/` — нельзя копировать только HTML.

```sh
# Полная переносимая папка для статического хостинга
python src/build.py dist/index.html
# Прежний формат: основной CSS/JS встроен в HTML; папки weather/, assets/ и tools/ остаются рядом
python src/build.py dist/index.html --inline
```

## Поиск

Раздел `#search` использует акварельный стиль главной: общую шапку и подвал,
бумажный фон, тонкие контуры и оранжевую кнопку «Найти». Доступны веб, картинки,
видео, карты, знания и код. Поиск теперь без фоновой иллюстрации и без
отдельной колонки для неё: форма занимает всю доступную ширину до 1440 CSS px,
а нижние блоки выровнены с ней. Поисковые системы выбираются компактными
вкладками. Провайдер и история остаются в локальном хранилище браузера.
На телефоне все типы поиска видны сразу, без горизонтальной прокрутки.

Проверка: `python tests/search_browser.py` (`CHROMIUM_PATH` — путь к Chromium).
Актуальная компоновка — [SEARCH_ART_AND_LAYOUT_RESULT.md](docs/SEARCH_ART_AND_LAYOUT_RESULT.md).

## Финансы и инженерия

Раздел `#tools` открывает ипотеку и кредит. `#tools/loan` — прямой вход; `#tools/science` — инженерный калькулятор. Прежний `#tools/calc` совместим и открывает инженерный экран.

- Кредит: аннуитет/дифференцированный график, календарные даты, разовые и регулярные досрочные взносы, уменьшение срока/платежа, изменения ставки, фиксированные расходы, графики и таблица, сценарии, CSV и JSON.
- Инженерный: безопасный парсер без eval, тригонометрия, логарифмы, степени, RAD/DEG, три функции на графике, параметр a, приближённые производная/интеграл/корень, таблица значений, SVG/CSV.
- Остальные семь инструментов сохраняют вычислительную логику и используют новое корпоративное оформление.

Финансовые расчёты — модель для планирования, не банковская оферта или ПСК. Примерные начальные значения не являются актуальными предложениями. Все допущения описаны в интерфейсе и [CORPORATE_TOOLS.md](docs/CORPORATE_TOOLS.md).

Фон — предоставленная пользователем панорама небоскрёбов, сжатая в локальный AVIF. Никаких CDN, внешних скриптов или передачи сумм. Текущий сценарий, сравнения и история сохраняются в localStorage; для переноса используйте экспорт.

## Живая погода

Большой маяк расположен в центре общей сцены. Небо, море и непрерывный берег занимают всю ширину.
Слева — текущие условия; справа — 7/14 дней; внизу — выбор часа и графики температуры, осадков и ветра.
Маяк и окружение меняются для дня, рассвета, заката, ночи, дождя, снега, тумана и грозы.

Поиск города и «Обновить» обращаются к Open-Meteo. До получения прогноза показан явно подписанный пример.
Кэш привязан к координатам, сведения о городе и текущем прогнозе передаются виджету главной.
Визуальные пресеты «Сцены» не подменяют числовые показатели. Есть пауза, учёт `prefers-reduced-motion`
и остановка анимации в скрытой вкладке/при выходе из маршрута.

- `weather/model.js` — нормализация, временные зоны, API и кэш.
- `weather/scene.js` — атмосферные слои, частицы и освобождение ресурсов.
- `weather/view.js` — взаимодействия и интерфейс.
- `weather/style.css`, `seamless.css`, `landscape.css`, `coast.svg` — сцена и адаптивная композиция.
- `src/weather-route.js` — ленивая загрузка и связь с главным экраном.
- `weather/viewport-fit.js`, `viewport-fit.css` — пропорциональное вписывание обеих сцен и доступная мобильная компоновка.

## Остальные сервисы и данные

### Родословная GEN

Раздел `#family` — браузерный генеалогический редактор на базе GEN: семейный граф,
таблица людей, карта поколений, биографии, фотографии и сохранение в IndexedDB.
Работает без Python-сервера. Данные можно вручную синхронизировать с собственным
**приватным** GitHub-репозиторием через GitHub REST API: SHA проверяются,
чужие изменения не перезаписываются. Для архивирования доступны JSON и ZIP.

Добавлены браузерный импорт/экспорт GEDCOM 5.5.1/7 и исходный `original.ged` в ZIP;
расширенное сравнение с Python GEN остаётся этапом приёмки. Персональные семейные данные в публичном AYYY не хранятся. Оставлена одна, более компактная классическая тема GEN.
На главной есть блок о владении архивом и отдельная справка `family/help/` с инструкцией по созданию личного приватного GitHub-репозитория.

[Устройство, возможности, ограничения и проверки](docs/FAMILY_PORTAL.md). Нагрузочные испытания 1000–30000 человек: [FAMILY_PERFORMANCE.md](docs/FAMILY_PERFORMANCE.md).

### Остров игр

Раздел `#games` — акварельный каталог с поиском, категориями, избранным и
18 играми внутри AYYY. В него перенесены все 16 игр из `i12309/Games`, включая
полную коллекцию из 48 раскрасок и «Мои работы»; сохранены прежние «2048» и
«Считаем играя». Игровые экраны оформлены в общей бумажной и бирюзовой палитре.
Настройки каталога и поддерживаемый играми прогресс хранятся в браузере.

[Устройство, состав и проверка игрового портала](docs/GAMES_PORTAL.md).

Калькуляторы, генератор паролей, обработка текста/JSON, палитра, игры и таймер
работают локально. Погода и валюты используют внешние источники; для LLM
необходима настройка собственного совместимого API.

Личные настройки сохраняются в браузере, не в репозитории. API-ключ LLM
не записывается в localStorage; история диалогов сохраняется локально.
Синхронизации между устройствами нет. Для важных данных используйте экспорт резервной копии.

### Сцены погоды: маяк и дерево v5

В погоде можно выбрать «Маяк» или «Дерево». Дерево использует PNG и подготовку древесины/листвы из утверждённого v5; изображение маяка сохранено. Последнее оформление сохраняется в браузере. Обе сцены используют один прогноз, выбранный город и час; дерево загружается только по запросу.

Рядом с переключателем «Маяк / Дерево» расположена кнопка «Настроить сцену». По умолчанию панель закрыта; повторное нажатие, крестик, Escape или нажатие вне панели скрывают её. У маяка доступны погода, освещение, время, сила осадков, ветер и вспышки. У дерева дополнительно доступны месяцы, четыре сезона и суточный цикл. Неактивные сезонные настройки у маяка не показываются.

Закрытие панели сохраняет ручные параметры до возврата к реальной погоде или перезагрузки. Текущий режим и кнопка «К реальной погоде» остаются под почасовым графиком, пауза — рядом с пояснением графика. Панель открывается поверх композиции и не меняет размер или положение дерева. Прогнозные цифры продолжают обновляться независимо; выбор дня/часа применяет серверный прогноз этого момента.

Сезон учитывает местный календарь города и полушарие. Вероятность осадков не используется как интенсивность. Сухая зима не включает снегопад или принудительный снежный покров. Сведения о подготовке, проверках и ограничениях — `docs/WEATHER_SCENE_INTEGRATION_RESULT.md`.

На настольном экране композиция обеих тем пропорционально вписывается в доступную ширину и высоту окна, включая статус просмотра и подвал. Открытие настроек не увеличивает высоту документа; размеры панели ограничены окном. При ширине менее 960 CSS px или высоте менее 540 CSS px используется обычная прокручиваемая композиция. Фон непрерывен до 4K; его исходные боковые стыки и верхние границы облаков сглаживаются при загрузке. Canvas учитывает DPR и использует до 3840×2160 пикселей, в том числе при системном масштабе 200%.

Проверка соответствия v5: `python tests/weather_v5_visual_browser.py` сравнивает пропорции, палитру и пиксели дерева во всех 12 месяцах с оригинальным HTML. Исправленный фон проверяется отдельно: `node --test tests/weather_tree_background.test.cjs` и `python tests/weather_viewport_browser.py` проверяют швы, 4K, границы всех открытых элементов, смену размера окна и доступность мобильных настроек. Для собственного Chromium задайте `CHROMIUM_PATH`.

## Удалённые разделы (8 ноября 2026)

Почта (Gmail), отслеживание посылок, Мастерская, Заметки и задачи и Мои закладки
полностью исключены из реестра сервисов, меню и исполняемых модулей. Существовавшие
раньше локальные данные пользователя **не очищаются** автоматически; стандартный
JSON-экспорт сохраняет их как часть резервной копии. Восстановление в действующем
интерфейсе применяется только к избранному и ярлыкам главной.

[Отчёт об удалении сервисов](docs/REMOVED_SERVICES.md).

### Компактная погода на телефоне (ноябрь 2026)

До 700 CSS px первый экран показывает город, температуру, состояние неба, диапазон дня, ощущаемую температуру, ветер и вероятность осадков. Дерево полностью помещается в оставшуюся часть экрана. По кнопке «Прогноз на 7 дней и по часам» открываются недельный и почасовой прогноз, управление паузой и исходная строка атрибуции. Поиск города, обновление и настройки сцены остаются в шапке. То же компактное размещение доступно для маяка; настольная композиция не изменена.

Реализация: `weather/mobile-compact.css`, `weather/tree-scene.js`. Проверки: `node --test tests/weather_tree_geometry.test.cjs` и `python tests/weather_viewport_browser.py` (Playwright/Chromium).
