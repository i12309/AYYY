# AYYY — ваш маяк в интернете

Статический портал: 22 сервиса, акварельная главная, каталог и динамическая погода с маяком.
Работает на GitHub Pages, без серверного приложения и без npm-сборки.

## Запуск и сборка

```sh
python src/build.py
python -m http.server 8000
```

Откройте `http://localhost:8000/`. Погода: `#weather`; независимый вход: `weather/`.

Готовый корневой `index.html` использует локальные CSS/JS из `src/`, снабжённые хешами для обновления кэша.
Модули погоды загружаются только при открытии её страницы. При публикации из `main` нужны
`index.html`, `.nojekyll`, `src/`, `assets/` и `weather/` — нельзя копировать только HTML.

```sh
# Полная переносимая папка для статического хостинга
python src/build.py dist/index.html
# Прежний формат: основной CSS/JS встроен в HTML; папки weather/ и assets/ остаются рядом
python src/build.py dist/index.html --inline
```

## Живая погода

Большой маяк расположен в центре общей сцены. Небо, море и непрерывный берег занимают всю ширину.
Слева — текущие условия; справа — 7/14 дней; внизу — выбор часа и графики температуры, осадков и ветра.
Маяк и окружение меняются для дня, рассвета, заката, ночи, дождя, снега, тумана и грозы.

Поиск города и «Обновить» обращаются к Open-Meteo. До получения прогноза показан явно подписанный пример.
Кэш привязан к координатам, сведения о городе и текущем прогнозе передаются виджету главной.
Визуальные пресеты «Сцены» не подменяют числовые показатели. Есть пауза, учёт `prefers-reduced-motion`
и остановка анимации в скрытой вкладке/при выходе из маршрута.

- `weather/model.js` — нормализация, временные зоны, API и кэш.
- `weather/scene.js` — атмосферные слои, частицы и освобождение ресурсов.
- `weather/view.js` — взаимодействия и интерфейс.
- `weather/style.css`, `seamless.css`, `landscape.css`, `coast.svg` — сцена и адаптивная композиция.
- `src/weather-route.js` — ленивая загрузка и связь с главным экраном.

## Проверки

```sh
node tests/model.test.cjs --fixture
python tests/weather_build_test.py
# Требуются Playwright и Chromium; CHROMIUM_PATH позволяет указать бинарник
python tests/weather_browser.py
```

34 проверки модели, 89 браузерных проверок, 6 тестов сборки. Браузерный стенд читает реальные файлы
проекта, но использует контролируемые ответы API и изолированное тестовое хранилище.
Это проверка интерфейса/интеграции, а не обещание доступности внешнего Open-Meteo.
Снимки можно создать с `AYYY_SCREENSHOTS=1`; они не нужны для запуска тестов.

## Остальные сервисы и данные

Калькуляторы, генератор паролей, обработка текста/JSON, палитра, рисование, игры, заметки,
таймер и закладки работают локально. Погода и валюты используют внешние источники;
посылки и рынки — виджеты; Gmail и LLM требуют настройки владельцем аккаунта.

Личные записи сохраняются в браузере, не в репозитории. API-ключ LLM и OAuth-токены Gmail не
записываются в localStorage; история диалогов и локальные почтовые черновики — записываются.
Синхронизации между устройствами нет. Для важных данных используйте экспорт резервной копии.
