# Здоровье · HUMAN в AYYY

Статический браузерный модуль `AYYY/#health`, работающий в GitHub Pages без сервера. Текущий код HUMAN (`C:\CODE\human`) служит образцом оформления и функций. Главная страница портала и расположение логотипов сохранены.

Данные загружаются заново. Конвертеров, поддержки старых версий и переноса SQLite/ZIP HUMAN нет. Поддерживаются новые записи/файлы и backup текущего зашифрованного формата.

## Что работает

- Анализы: группировка, графики, точность даты, исходные результаты, референсы, классификация и избранное.
- Новые CSV/XLSX/PDF с текстовым слоем: локальный разбор, сопоставление колонок, редактирование и подтверждение. PDF, изображения и текст открываются внутри журнала.
- Показатели, явные эпизоды болезни, связи с медкартой и история.
- Медкарта с частичными датами, статусами и подробностями.
- Фактические приёмы/пропуски и отдельные напоминания; локальные уведомления включаются явно и работают при открытом журнале.
- Генетические записи из отчётов: категории, поля источника, частичные даты, поиск, документы и история. VCF/JSON остаются исходными файлами, без интерпретации генома.
- Питание с итогами известных значений и активность по дням с графиком, поиском и историей.
- Профиль с возрастом, ростом и зоной; карточки данных и история действий с фильтрами, поиском и переходами.
- Рекомендации: анкета, снимки текущих данных, загрузка отдельных JSON-рецензий, источники, статусы и предупреждение об устаревании. Автоматических назначений и вызовов ИИ нет. [Формат пакета/рецензии](RECOMMENDATIONS.md).
- Несколько изолированных профилей, восстановление текущих зашифрованных копий после проверки фразы и атомарная смена фразы доступа; синхронизация с приватным GitHub.

Все записи шифруются WebCrypto AES-GCM/PBKDF2 перед IndexedDB/GitHub. Ключ, фраза и GitHub-токен не сохраняются на диск. GitHub получает только `health-data/v1/vault.json`; модуль родословной хранит данные отдельно в `family-data/`. Конфликт не перезаписывает чужую версию автоматически.

Восстановление принимает только полную текущую структуру: отсутствующие разделы старых форматов не создаются автоматически. Перед записью копия расшифровывается и показывается для подтверждения; существующий журнал сохраняется, восстановленный получает отдельный ID. Смена фразы меняет ключ/соль/IV всего журнала в одной локальной записи и закрывает другие вкладки. Ранее скачанные копии сохраняют прежнюю фразу.

Текущие пределы: вложение до 2 МиБ, расшифрованный журнал до 28 МиБ. HTTPS или localhost необходим для WebCrypto. Внешних обработчиков, отправки ИИ, аналитики и серверной базы нет.

## Демо

На стартовом экране нажмите «Открыть демо без регистрации» или перейдите в `AYYY/#health/demo`. Демо содержит только вымышленные сведения: 68 анализов, 33 измерения, эпизоды, медкарту, генетические записи, препараты, приём, напоминание, питание/активность и документы. Оно создаётся в памяти, не записывает IndexedDB и не обращается к GitHub. Все изменения исчезают после выхода/сброса/перезагрузки.

## Разработка

```powershell
node --test tests/health_model.test.cjs tests/health_demo.test.cjs tests/health_care.test.cjs tests/health_diary.test.cjs tests/health_genetics.test.cjs tests/health_journal.test.cjs tests/health_recommendations.test.cjs
python -X utf8 tests/health_diary_browser.py
python -X utf8 tests/health_genetics_browser.py
python -X utf8 tests/health_journal_browser.py
python -X utf8 tests/health_recommendations_browser.py
python -X utf8 tests/health_browser_matrix.py
python -X utf8 src/build.py dist/index.html
```
