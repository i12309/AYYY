# Игры внутри AYYY

Полный локальный набор 16 игр из [i12309/Games](https://github.com/i12309/Games),
зафиксированный на коммите
[`591c541f58e2e9f24450349db3623635d4b4b920`](https://github.com/i12309/Games/commit/591c541f58e2e9f24450349db3623635d4b4b920).
`SOURCE.json` хранит исходные SHA-256 каждого перенесённого файла.

## Что перенесено

Скопированы `assets/`, `shared/`, `games/` и `works.html`: уровни, генераторы
заданий, рабочий процесс раскраски, все 48 рисунков, загрузка изображения,
мастерские и полка из 24 работ с JSON-импортом/экспортом. Внешние библиотеки,
сервисы и загрузка кода из исходного репозитория при запуске не нужны.

HTML подключает последним `shared/ayyy-theme.css` и в `<head>` —
`shared/ayyy-bridge.js`. Заголовки документов и `theme-color` адаптированы к AYYY.
Общий CSS меняет оформление интерфейса и игровых поверхностей, сохраняя
цветовые различия, необходимые для правил игр. У лабиринта и шариковой аркады
дополнительно заменена декоративная палитра Canvas; координаты, игровые
цвета шаров, физика и правила сохранены. В «Найди пару» исправлено обновление
счётчика сразу после найденной пары: раньше число обновлялось только при
следующем ходе или завершении. Игровые JS-файлы, кроме этих двух изменений
отрисовки и исправления счётчика, совпадают с зафиксированным источником.

`index.html` служит запасным переходом в `../../index.html#games`, а не второй
копией каталога. Сами игры остаются доступными как отдельные HTML-страницы.

## Связь с порталом

Игры открываются в документе того же origin, внутри `iframe`. Это отделяет
их глобальные стили и клавиатурные обработчики от погоды и остальных
разделов AYYY. Встроенный режим определяется без изменения URL и запускает
те же игровые модули. Повторяющийся логотип скрыт, ссылки на «Мои работы»
остаются в компактной навигации. Динамические названия рисунков и уровней
остаются видимыми.

У статических головоломок повторяющиеся названия внутри поля и боковой панели
скрываются только во встроенном режиме; главный заголовок принадлежит порталу.
Номер уровня, описание задания и статистика остаются на месте. Палитра сот
переопределяется только SVG-стилями: значения чисел и алгоритм слияния неизменны.

Все сообщения отправляются в `location.origin`; получатель обязан также
проверить `event.source === iframe.contentWindow`. Мост принимает настройки
только от непосредственного родителя с тем же origin.

| Сообщение | Направление | Поля |
| --- | --- | --- |
| `ayyy-games:ready` | Игра → портал | `title`, `path`, `height` |
| `ayyy-games:height` | Игра → портал | `height` в CSS px |
| `ayyy-games:location` | Игра → портал | `path`, `title` после смены уровня |
| `ayyy-games:progress` | Игра → портал | `gameId`, `label`, `path` |
| `ayyy-games:catalog` | Игра → портал | Возврат в каталог |
| `ayyy-games:escape` | Игра → портал | Выход из развёрнутого режима, если Escape не занят самой игрой |
| `ayyy-games:settings` | Портал → игра | `palette: "paper" \| "sand"`, `quiet: boolean` |

`path` содержит путь и query текущего документа. Родитель должен проверять
его по разрешённому списку локальных игр перед повторным открытием. Сообщение
о прогрессе — краткая подпись для каталога; сами игровые данные не пересылаются.
Повторяющиеся подписи и изменения одного лишь таймера не создают новых
сообщений. Цвета и тихий режим не меняют правила или состояние игры. Тихий режим
отключает переходы интерфейса; необходимое движение в игровых Canvas сохраняется.

У пяти исходных игр, которые не обновляли URL при смене уровня (пары, лабиринт,
соты, гайки, стрелки), мост отражает фактически выбранный уровень из их интерфейса
в `?level=`. Это не меняет игровые сохранения и позволяет возобновить именно
выбранную сложность, вместо прежнего значения из стартовой ссылки.

Высота вычисляется по содержимому `.site-shell`. Встроенный документ не имеет
`min-height:100vh`, а высота игровых полей зависит от ширины и ограничена сверху.
Поэтому изменение размера `iframe` не вызывает цикл роста его высоты. При
уходе со страницы мост освобождает наблюдатели и останавливает чтение вслух.

## Совместимость сохранений

Исходные ключи `igroland.*`, `igroland-pixel-paint-v1:*`, формат данных и палитры
рисунков не переименованы. На GitHub Pages оба исходных проекта находятся на
одном origin `https://i12309.github.io`, поэтому доступные этому origin игровые
сохранения продолжают читаться. При открытии на другом домене браузер использует
другое локальное хранилище. Полка «Мои работы» сохраняет исходные команды
экспорта и импорта JSON.

## Проверка после обновления источника

Сначала сравнить ревизии и схемы данных; затем перенести исходные изменения,
сохранив подключения темы/моста, два изменения палитры и исправление счётчика пар. Проверить все локальные
`href`/`src`, 16 игровых точек входа, раскраски/галерею и `works.html`. Запустить
исходные Node-проверки правил и интеграционные проверки AYYY. Проверить браузером
смену уровня, возврат в каталог, восстановление сохранения и узкий экран.

Не следует переносить сохранения через сброс или переименование storage-ключей.
