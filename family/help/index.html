ГДЕ ХРАНЯТСЯ ДАННЫЕ

Два варианта хранения

01 · ПО УМОЛЧАНИЮ

В вашем браузере

GEN хранит людей, связи и фотографии в IndexedDB на вашем устройстве. Для создания дерева не нужен аккаунт GitHub. Очистка данных браузера может удалить локальный архив.

02 · ПО ЖЕЛАНИЮ

В вашем GitHub

Вы выбираете собственный приватный репозиторий. После нажатия «Синхронизировать» браузер отправляет файлы непосредственно в GitHub. История версий остаётся в вашем репозитории.

Сервер AYYY раздаёт только статический код сайта. Он не принимает и не хранит ваши семейные данные. При синхронизации файлы передаются в GitHub — это отдельный сервис.

ПОШАГОВАЯ ИНСТРУКЦИЯ

Создайте собственный GitHub-репозиторий

Достаточно бесплатного аккаунта GitHub. Настройка выполняется один раз; сам GEN продолжает работать в браузере.

1

Создайте приватный репозиторий

Откройте создание репозитория GitHub. Введите название, например my-family-tree, выберите Private и включите Add a README file, чтобы появилась ветка main.

2

Создайте токен с ограниченными правами

Откройте Settings → Developer settings → Personal access tokens → Fine-grained tokens. Разрешите доступ только к выбранному репозиторию и установите Contents: Read and write. Задайте срок действия. Токен никому не передавайте.

3

Сохраните дерево из GEN

В редакторе нажмите «Локальное дерево», введите имя-пользователя/my-family-tree, ветку main и токен. Затем нажмите «Синхронизировать». Сохранение не выполняется автоматически.

4

Откройте архив на другом компьютере

В GEN выберите «Открыть из GitHub», укажите тот же репозиторий и токен, затем выберите дерево. После новых изменений снова нажмите «Синхронизировать».

Что хранится в GitHub 
family-data/
  trees/
    название-дерева/
      tree.json        Люди, связи и биографии
      tree.ged         Текущий экспорт GEDCOM
      original.ged     Оригинал импортированного GEDCOM (если есть)
      media/           Фотографии и документы

Папки и файлы генерируются при синхронизации. Не переводите семейный репозиторий в публичный режим.

КОНФИДЕНЦИАЛЬНОСТЬ

Что важно знать

Нет базы на сервере AYYY

В локальном режиме сведения о родственниках и фотографии остаются в браузере. AYYY не владеет вашим деревом.

GitHub — ваше облачное хранилище

Если включена синхронизация, данные обрабатывает GitHub. Доступ определяется приватностью репозитория и выданными вами разрешениями.

Токен не сохраняется GEN

Токен находится в памяти открытой вкладки, а не в IndexedDB или localStorage. После перезагрузки его может понадобиться ввести заново.

Нужны резервные копии

Скачивайте JSON, GEDCOM или ZIP. При очистке браузера локальные данные могут исчезнуть; автоматической фоновой синхронизации пока нет.

ВОПРОСЫ

Частые вопросы

GitHub обязателен?

Нет. Можно работать локально. GitHub нужен для синхронизации и восстановления на другом устройстве.

Данные могут увидеть другие?

Локальный архив доступен пользователям этого браузера и устройства; приватный репозиторий — тем, кому вы разрешили доступ, а также в рамках правил GitHub. Не публикуйте сведения о родственниках в открытом репозитории.

А если два компьютера изменили одно дерево?

GEN обнаруживает несоответствие версии и не перезаписывает удалённое дерево молча. Сохраните локальную резервную копию и проверьте конфликт перед продолжением.

Как перенести старый GEN?

Импортируйте JSON или GEDCOM. Полный ZIP сейчас можно экспортировать, но импорт ZIP с фотографиями ещё находится в плане доработки.
