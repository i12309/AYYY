# Оформление здоровья из HUMAN

Модуль `health/` использует оформление проекта `C:\CODE\human`: исходные `web/src/style.css` и `web/src/labs/labs.css` перенесены в `human.css` и `human-labs.css`, логотип — из `web/public/icon.svg`. Локальный SVG-спрайт содержит используемые значки Lucide; лицензия находится в `health/LUCIDE-LICENSE.txt`.

Воспроизведены боковая панель 208 px, верхняя панель 58 px, типографика, цвета, отступы, карточки обзора, таблица групп анализов, графики, формы и мобильная навигация. `human-adapter.css` связывает эти стили с DOM браузерной версии. Поиск в шапке работает по текущему открытому профилю; кнопка «Добавить» открывает выбор существующих типов записей.

Модуль остаётся статическим HTML/JS внутри изолированного iframe AYYY. Шифрование, IndexedDB и существующая синхронизация GitHub сохранены. Серверные разделы HUMAN этим изменением не переносятся. Личные данные из исходного проекта не используются; демонстрация содержит только вымышленные записи.

## Проверки

```powershell
node --test tests/health_model.test.cjs tests/health_demo.test.cjs
python tests/health_browser.py
python src/build.py
python src/build.py dist/index.html
python -X utf8 tests/weather_build_test.py
```

Браузерная проверка требует установленного Python Playwright и Chromium. Использует временный контекст, локальные файлы и синтетические данные: проверяет геометрию HUMAN, редактирование, поиск, разделы при ширинах 360–1920 px, мобильное меню, изоляцию демо, сохранение зашифрованной записи после перезагрузки и встраивание в портал. Живой обмен с приватным GitHub не входит в этот прогон.

## Стартовый экран и навигация (10.11.2026)

- Входной экран HUMAN занимает доступную ширину до 1220 px: в верхней строке рядом с логотипами — заголовок и подпись, под ними — демо-плашка во всю ширину и уменьшенной высоты. Создание и подключение — две равные карточки, восстановление файла — компактная горизонтальная форма. На телефонах всё перестраивается в одну колонку.
- На стартовом экране логотип AYYY находится слева от HUMAN; на рабочем экране HUMAN остаётся единственным логотипом боковой панели, а компактный AYYY перенесён в верхнюю строку слева от хлебных крошек «Личное пространство». HUMAN при наведении сохраняет исходный цвет.
- Логотип HUMAN переключает на обзор журнала внутри модуля, не покидая HUMAN; только AYYY ведёт в родительский портал.
- В браузерный тест добавлены проверки расположения логотипов (включая AYYY в шапке рабочего экрана), перехода на обзор, наличия основных форм и отсутствия горизонтальной прокрутки на экранах 360–1920 px.

## Сверка с текущим HUMAN, 2026-11-10

`main` обновлена до `0b1c725` перед работой. Сервер `http://192.168.3.161:8000/` доступен, но в отдельной браузерной сессии показывает вход. Авторизованные экраны на сервере без тестовой учётной записи не проверены. Сверка внутренних экранов выполнена по текущим `web/src/labs/AnalytePage.tsx`, `HistoryChart.tsx`, `documents/DocumentDetail.tsx` в `C:\CODE\human`.

Страница анализа теперь использует исходную структуру HUMAN: сводку из четырёх блоков, динамику и панель выбранного измерения, полную таблицу истории. Точки выбираются мышью или клавиатурой, даты расположены пропорционально времени, исходные референсы сохранены, среднее отмечено пунктиром. В списке работает фильтр вне референса. Текстовые и растровые документы открываются внутри журнала; PDF пока скачивается для просмотра.

Сохранены входная страница, расположение логотипов и главная страница AYYY. Изменения данных остаются в существующем зашифрованном хранилище. Это сближение существующих сценариев, а не полный перенос серверного HUMAN: миграция SQLite, разбор PDF/XLSX, классификация анализов, расширенные дневники, напоминания и генетика остаются в плане `HUMAN_BROWSER_PORT.md`.

[Экран анализа](health-ui/analyte-1440.png). Браузерные проверки включают выбор исходного измерения, просмотр документа, адаптивность и сохранность размещения логотипов.
