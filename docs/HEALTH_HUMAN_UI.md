# Интерфейс здоровья HUMAN в AYYY

## Актуальная модель

По уточнению пользователя данные загружаются заново. Конвертеры старых версий HUMAN, импорт SQLite/ZIP и совместимость с прежними структурами удалены, включая миграционные тесты и SQL.js. Обычный импорт новых CSV/XLSX/PDF и восстановление текущего зашифрованного vault.json остаются.

Исходник оформления — текущий `C:\CODE\human`. Используются его CSS shell, analyses, medical, health, care и diary; адаптация находится в `health/human-adapter.css`. Все стили ограничены отдельным iframe. Главная страница портала и расположение AYYY/HUMAN сохранены. Для живого сравнения авторизованного экрана HUMAN ещё нужен доступ; визуальное соответствие сейчас проверяется по его коду, CSS и локальным снимкам AYYY.

## Рабочие разделы

Анализы группируются только при совместимых показателе/единице/материале/методе. Исходные результаты, пределы, качественные значения и точность даты сохраняются. Общие референсы и избранное относятся к группе и не подменяют норму исходного бланка. Импорт новых файлов проходит сопоставление колонок и подтверждение редактируемого черновика; PDF/XLSX/CSV обрабатываются локально. Исходник связан с результатом и доступен для просмотра/скачивания.

Генетика использует карточки и поля текущих `genetics/GeneticsPage.tsx`, `FindingForm.tsx` и `app/AppDialogs.tsx`. Новые ручные записи содержат результат, поставщика, категорию, метку отчёта, исследование, точность даты, гены, варианты, исходное пояснение, версию метода, URL и документ-источник. Карточки поддерживают поиск по названию/поставщику, категории и страницы по 50 записей. Общий поиск находит также исходные поля и открывает подробности. Исправления сохраняют прежние факты. Неизвестный день/месяц не дополняется; отсутствующие варианты, сборка, strand и генотип не восстанавливаются. Метка «По отчёту: внимание» остаётся сведением поставщика, а не вычисленным заключением. Вложения VCF/JSON показываются как текст и скачиваются побайтово; автоматического разбора генома или клинических выводов нет. Из документа можно вернуться к результату. Внешняя ссылка появляется только после проверки HTTP(S) и не открывается автоматически.

В показателях есть виды домашних измерений, история, выбранная запись и график; давление отображается двумя линиями. Эпизод содержит собственное описание/сведения врача и явное состояние. Истечение подтверждения не означает выздоровления, отсрочка не подтверждает болезнь. Подтверждение/завершение/отсрочка 1/3/7 календарных дней сохраняются в истории; ручное неоднозначное время требует UTC offset.

Медкарта включает аллергии, препараты/добавки, прививки, состояния, операции и другие сведения. Сохраняются подробные факты, статус, источник сведений, точность начала/окончания, ссылки на документ/эпизод и история исправлений.

Приём/пропуск препарата и напоминание — разные сущности. Фактическое событие не может быть будущим и не меняет плановую дозу. Напоминания имеют свою зону и разовое/ежедневное расписание, паузу, выполнение, пропуск и отсрочку 15/60/180 минут. Выполнение не создаёт приём. DST: отсутствующее ежедневное время пропускается, повторяющееся используется один раз в ранний момент. Браузерные уведомления включаются явно, содержат только общий текст и работают при открытом разблокированном журнале.

Питание и активность — отдельные компактные разделы, как в HUMAN. Еда хранит точное время в зоне профиля и значения для всей порции; пустое число остаётся null, введённый ноль остаётся нулём. Итог показывает только известную сумму и число заполненных записей; поиск/вся история не меняют итог выбранного дня. Активность хранит одну запись на день: шаги, сон/упражнения в минутах, вид нагрузки и заметки. График пропускает неизвестные значения и открывает день с клавиатуры. История, исправления, удаление и явное повторное создание дня сохраняются. Формы встроены в страницу, незавершённый ввод остаётся при фильтрации.

Профиль повторяет карточки текущего `profile/ProfilePage.tsx`: личные сведения, данные, медкарта, документы, приёмы и история. Форма проверяет обязательное имя, дату рождения, рост и зону. Возраст учитывает день рождения в зоне профиля. Для возраста до 20 лет доступна история роста в показателях; скрытый основной рост не затирается.

История использует текущие действия, а не даты обследований: добавление, исправление, удаление, импорт, профиль, восстановление и смену фразы. Фильтры/поиск и страницы по 50 событий; переход к исходной записи или к сохранённому событию удаления. Выполнение напоминания остаётся действием напоминания и не создаёт приём. Старые снимки не реконструируются.

## Сохранение и GitHub

Открытые данные существуют в памяти. IndexedDB и GitHub получают AES-GCM envelope; фраза и токен не пишутся на диск. GitHub использует только `health-data/v1/vault.json` в выбранной приватной ветке. `family-data/` остаётся отдельным модулем.

Запись проверяет ожидаемый архив и метаданные в одной транзакции IndexedDB. Одновременный автор не может перезаписать новую версию. Квота откатывает изменение, оставляя редактор для повтора. Без сети локальное изменение остаётся доступным и ожидает отправки. Блокировка/смена профиля отменяет запоздавшие результаты чтения, шифрования, открытия и сетевых запросов. Уже отправленный запрос GitHub отозвать нельзя. Между устройствами конфликт блокируется и разрешается вручную с сохранением backup.

Текущий backup сначала расшифровывается и проверяется фразой, затем показывает состав для подтверждения. Он не записывается при неверной фразе, повреждении или отказе хранилища. Повторное восстановление создаёт отдельный журнал, сохраняя исходный; подключение GitHub не переносится автоматически. Смена фразы повторно подтверждает текущую, генерирует новую соль/ключ/IV и атомарно сохраняет все записи и вложения. Ошибка оставляет прежний архив; блокировка отменяет ещё не записанное шифрование. Другие вкладки закрываются; старый backup продолжает открываться своей прежней фразой.

Живой тест TEST_TREE использует отдельную временную ветку с синтетическими зашифрованными данными. Проверены транспорт, полное UI-сохранение расписания, восстановление вторым браузером и конфликт, сохраняющий локальный черновик и remote. Дополнительно проверены смена фразы через UI, синхронизация нового envelope и открытие третьим независимым браузером с новой фразой. Токен взят из `gh` только в память, тестовая ветка удаляется в finally.
