# Оформление здоровья из HUMAN

Модуль `health/` использует оформление проекта `C:\CODE\human`: исходные `web/src/style.css` и `web/src/labs/labs.css` перенесены в `human.css` и `human-labs.css`, логотип — из `web/public/icon.svg`. Локальный SVG-спрайт содержит используемые значки Lucide; лицензия находится в `health/LUCIDE-LICENSE.txt`.

Воспроизведены боковая панель 208 px, верхняя панель 58 px, типографика, цвета, отступы, карточки обзора, таблица групп анализов, графики, формы и мобильная навигация. `human-adapter.css` связывает эти стили с DOM браузерной версии. Поиск в шапке работает по текущему открытому профилю; кнопка «Добавить» открывает выбор существующих типов записей.

Модуль остаётся статическим HTML/JS внутри изолированного iframe AYYY. Шифрование, IndexedDB и существующая синхронизация GitHub сохранены. Серверные разделы HUMAN этим изменением не переносятся. Личные данные из исходного проекта не используются; демонстрация содержит только вымышленные записи.

## Проверки

```powershell
node --test tests/health_model.test.cjs tests/health_demo.test.cjs
python tests/health_browser.py
python src/build.py
python src/build.py dist/index.html
python -X utf8 tests/weather_build_test.py
```

Браузерная проверка требует установленного Python Playwright и Chromium. Использует временный контекст, локальные файлы и синтетические данные: проверяет геометрию HUMAN, редактирование, поиск, разделы при ширинах 360–1920 px, мобильное меню, изоляцию демо, сохранение зашифрованной записи после перезагрузки и встраивание в портал. Живой обмен с приватным GitHub не входит в этот прогон.

## Стартовый экран и навигация (10.11.2026)

- Входной экран HUMAN занимает доступную ширину до 1220 px: заголовок и демо расположены рядом на широком экране, создание и подключение — две равные карточки, восстановление файла — компактная горизонтальная форма. На телефонах всё перестраивается в одну колонку.
- HUMAN и AYYY получили отдельные словесные логотипы в шапке входа и боковой панели журнала. Логотип AYYY повторяет шрифт, наклон и оранжевую точку главной страницы портала.
- Логотип HUMAN переключает на обзор журнала внутри модуля, не покидая HUMAN; только AYYY ведёт в родительский портал.
- В браузерный тест добавлены проверки обоих логотипов, перехода на обзор, наличия основных форм и отсутствия горизонтальной прокрутки на экранах 360–1920 px.
