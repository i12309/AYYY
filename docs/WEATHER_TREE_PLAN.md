# AYYY Weather · дерево и 12 месяцев

План: две выбираемые темы «Маяк» и «Дерево» на одном погодном интерфейсе. Сцену маяка не удалять и не регрессировать. Новый рисунок состоит из отдельных SVG: дерево (ствол, ветки), горы, холм. Листва динамически создаётся детерминированным SVG на основе календарного месяца, географического полушария и погодных условий; время дня определяет освещение, осадки — общие с маяком.

Контрольные точки:
1. Закоммитить автономные SVG-слои и этот план.
2. Создать генератор листвы, сезонную модель с 12 месяцами, анимацию падающих листьев, снежный покров.
3. Интегрировать переключатель в портал и автономную страницу без изменения API прогноза, расчётов и сохранения данных.
4. Добавить управление месяцами/предпросмотром и проверку даты выбранного города, отдельную отметку демонстрационного режима.
5. CSS слоёв, адаптивность, reduced-motion, тесты и README.

Без внешних зависимостей. Живые данные не заменять условными. «Месяц» влияет на декорацию, не на прогноз.
