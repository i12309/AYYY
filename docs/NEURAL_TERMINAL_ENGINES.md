# AYYY — нейронный терминал: три режима ответов

Дата: 10 ноября 2026. Ветка: main. Все режимы работают на GitHub Pages без собственного API-шлюза.

## Переключатель

- **DEMO / OFFLINE** (начальный режим) — старый локальный симулятор ответов. Не делает сетевых запросов.
- **PUBLIC / NET** — напрямую из браузера к выбранному внешнему провайдеру:
  - **OVH / Qwen3.8-27B** (по умолчанию внутри PUBLIC) — прямой OpenAI-совместимый запрос к \`https://oai.endpoints.kepler.ai.cloud.ovh.net/v1/chat/completions\`, без токена. У сервиса есть ограничения на анонимные обращения (документация: 2 запроса/минуту на IP и модель). Ответ обрабатывается как SSE.
  - **Hugging Face / Qwen3** — через \`@gradio/client@2.7.2\` напрямую к публичному Space \`Qwen/Qwen3-Demo\`. API Space проверяется через \`view_api()\` в момент обращения. Используется \`/add_message\` с четырьмя параметрами исходного Gradio-сценария. **Экспериментально:** Space может менять API, требовать авторизацию или ограничивать очередь. Не гарантируется, что каждый запрос будет обслужен.
  - В поле SPACE можно указать другой \`owner/name\`. Для обычных Gradio ChatInterface есть попытка отправить \`[prompt, history]\`; сложные схемы других Spaces могут не поддерживаться. Требуется публичный Space и вызываемый endpoint.
- **LOCAL / WEBGPU** — \`@mlc-ai/web-llm@0.2.87\`; запуск модели на GPU посетителя. Первый запуск скачивает веса в кеш браузера, что может потребовать сотни мегабайт или гигабайты. Параметры выбора: Qwen2 0.5B, Llama 3.2 1B, Qwen2 1.5B, с подбором малого совместимого fallback из каталога библиотеки.

## Принципы

- Нет сервера AYYY, прокси, ключей API и собственного тарифицируемого инференса.
- История диалога живёт только в памяти страницы; при перезагрузке сбрасывается. У WebLLM может кешироваться **модель**, не переписка.
- Публичный режим отправляет запрос и последние сообщения внешнему сервису; это явно указано у переключателя.
- Ошибки 429 / CORS / API / отсутствия WebGPU отображаются пользователю. **Никакого автоматического перехода на имитацию без его выбора.**
- На странице сохранены псевдографика, сканлайны, свечение, телеметрия, RESET, добавлена кнопка STOP.
- Основной маршрут: \`https://i12309.github.io/AYYY/#ai\`. Встроенный изолированный документ: \`terminal/index.html\`.

## Проверки

\`\`\`bash
node --test tests/neural_terminal.test.cjs tests/retired_services.test.cjs
python src/build.py
\`\`\`

Тесты без внешней сети проверяют поток SSE OVH, структуру Gradio/Qwen, кэш WebLLM-движка, отсутствие токенов, маршрут и сборку. Они **не подтверждают**, что реальные внешние серверы доступны в браузере посетителя в данный момент. Для окончательной интеграционной приёмки нужно выполнить по одному живому запросу в PUBLIC / OVH, PUBLIC / HF и WEBGPU на устройстве с WebGPU. При блокировке CORS браузером это невозможно исправить только кодом страницы.
