# AYYY Weather · дерево на холме, двенадцать месяцев

Дата: 6 ноября 2026. Рабочая ветка: `main`.

## Результат

Два равноправных пейзажа в одном разделе «Погода»: **Маяк** и **Дерево**. Выбор сохраняется в `localStorage` по ключу `ayyy:v1:weather.scene.subject`; маяк остаётся доступным в любой момент. Текущий город, 7/14 дней, почасовой прогноз, единицы измерения и визуальные настройки общие.

Три локальных SVG: `weather/assets/tree-trunk.svg` (ствол и ветви), `tree-mountains.svg` (дальние горы и озеро), `tree-hill.svg` (холм, камни и травы). Отдельный `tree-art.js` детерминированно строит SVG-листву выбранного месяца. В `tree.css` описаны сезонные цвета, дождь, снег, туман, сумерки, ночь и падающие листья.

Учитывается широта: для Южного полушария сезонный цикл развёрнут на шесть месяцев. Это художественная модель **умеренного климата**, не ботанический прогноз каждого вида деревьев и не точная дата листопада в конкретном городе.

## Откуда месяц и погода

Автоматический месяц вычисляется из даты выбранного часа или дня прогноза через `M.dateKey(time, timezone)`, а не по часовому поясу компьютера. Учитывается широта выбранного города. Если пользователь не выбирал будущий день, используется текущий момент города.

Кнопки **По дате** и Янв–Дек позволяют просмотреть оформление другого месяца. Погода и день/ночь также имеют режим предпросмотра. Эти переключатели изменяют только рисунок: цифры прогноза, API, даты и показатели не подменяются. В ручном режиме показано предупреждение «Предпросмотр оформления».

Осадки анимируются прежним `weather/scene.js` на общем Canvas и управляются прежним прогнозом. Облака, солнце/луна, рассвет и туман тоже используются повторно. При паузе, скрытой вкладке и `prefers-reduced-motion` анимация останавливается. После выхода со страницы обработчики и наблюдатели удаляются.

## Источники и ограничения

Новых сторонних запросов нет. Фотографии и сторонние библиотеки для дерева не используются. SVG и JavaScript размещены на GitHub Pages, вне пользовательских данных. Как и прежде, при недоступности погодного API используются последний кэш или явно подписанный демо-прогноз. Анимированный пейзаж иллюстративен.

**Проверки:** `node tests/weather-tree.test.cjs`, `node --check weather/tree-art.js`, `node --check weather/view.js`, `node --check weather/scene.js`, `python src/build.py`. Проверка данных Open-Meteo проводится отдельно от графического кода.
