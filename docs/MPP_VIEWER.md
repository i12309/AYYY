# AYYY Project Viewer: первый этап

## Что реализовано

Новый сервис AYYY: #mpp (также доступен из каталога и бокового меню).
Файл открывается локально из браузера через File API, без загрузки на
сервер, без API-ключа, Node.js, Java или Microsoft Project у пользователя.

- Поддерживаемые входы: MPP, MPT, MPX, Microsoft Project XML (MSPDI).
- Отдельно загружаемый бинарный парсер mpxj-ts (LGPL-2.1-or-later).
- Диаграмма Ганта с масштабом день / неделя / месяц и прогрессом задач.
- Дерево задач: WBS, сворачивание групп, даты, длительность, готовность.
- Поиск, карточка задачи (примечания, ресурсы, предшественники, последователи).
- Таблица ресурсов и назначений, выгрузка задач в CSV с защитой от
  формул при открытии в табличных редакторах.
- Демонстрационный план с вымышленными данными; проект не хранится в
  localStorage и сбрасывается при перезагрузке.
- Компактное оформление AYYY, адаптация для небольших экранов.

Никаких сетевых запросов с содержимым MPP нет. Сайт загружает собственный
модуль чтения из папки mpp/vendor; ссылки на сторонние проекты в
документации не используются как внешние сервисы обработки.

## Запуск

    python src/build.py
    python -m http.server 8000

Затем: http://localhost:8000/#mpp

Работает и как обычный статический сайт на GitHub Pages. GitHub Pages
по умолчанию публикует main, поэтому работа в отдельной ветке сама по
себе не меняет опубликованный портал.

## Тесты

    node --check mpp/model.mjs
    node --check mpp/viewer.mjs
    node --check src/mpp-route.js
    node --test tests/mpp_model.test.mjs
    python tests/mpp_build_test.py

Fixture: tests/fixtures/ayyy-project-sample.xml. Он вымышленный и может
быть открыт через интерфейс для проверки распознавания MSPDI.

Тесты модели, CSV и чтения XML не заменяют проверку на наборе реальных
MPP разных версий и размеров. До такого тестирования корректность
длительностей, календарей и назначений следует сверять с Microsoft Project.

## Известные ограничения первого этапа

- Только чтение: нет редактирования или сохранения обратно в MPP.
- В строках Ганта отображаются задачи и вехи. Связи доступны текстом
  в карточке; линии связей, базовый план и критический путь в Ганте
  запланированы на следующие этапы.
- Не все проприетарные поля и нестандартные календари MPP поддерживаются
  браузерным парсером. Защищённые паролем файлы могут не открыться.
- При ошибке чтения MPP пользователь может экспортировать Project XML
  в Microsoft Project и открыть его в этом же просмотрщике.
- Лимит размера выбранного файла: 40 МиБ. Крупные проекты могут
  обрабатываться дольше; worker и виртуализация строк — следующие этапы.
- Для длинных временных диапазонов Гант отображает не более 10 000 дней.
- Экспорт CSV только для задач. Полноценный обмен Jira ↔ MSPDI и
  редактирование — отдельные будущие этапы.

## Архитектура

- src/mpp-route.js — регистрация AYYY-маршрута и загрузка JS/CSS.
- mpp/viewer.mjs — локальный выбор файла, таблицы, диаграмма, UI-события.
- mpp/model.mjs — нормализация структуры и не зависящие от DOM операции.
- mpp/style.css — оформление без зависимостей от UI-фреймворков.
- mpp/vendor/mpxj-ts/mpxj.mjs — независимый LGPL-парсер бинарного MPP.
- mpp/vendor/mpxj-ts/src — соответствующий TypeScript-код парсера.
- mpp/vendor/mpxj-ts/PROVENANCE.md — происхождение и сборка библиотеки.
