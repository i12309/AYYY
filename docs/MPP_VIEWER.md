# AYYY Project Viewer: первый этап

## Что реализовано

Новый сервис AYYY: #mpp (также доступен из каталога и бокового меню).
Файл открывается локально из браузера через File API, без загрузки на
сервер, без API-ключа, Node.js, Java или Microsoft Project у пользователя.

- Поддерживаемые входы: MPP, MPT, MPX, Microsoft Project XML (MSPDI).
- Отдельно загружаемый бинарный парсер mpxj-ts (LGPL-2.1-or-later).
- Диаграмма Ганта с масштабом день / неделя / месяц, прогрессом задач, линиями связей FS/SS/FF/SF и полосами Baseline. Слои связей и базового плана можно скрывать.
- Дерево задач: WBS, сворачивание групп, даты, длительность, готовность.
- Сведения о выбранной задаче открываются в закреплённой панели справа от Ганта, не перекрывая шкалу. На узких экранах панель располагается под диаграммой.
- Ширина таблицы задач регулируется мышью (перетаскивание разделителя) или клавишами ←/→, Home/End; размер сохраняется при перестроении интерфейса в рамках текущего открытия страницы.
- Компактная шкала Ганта (день/неделя/месяц), уменьшенные отступы диапазона и высота заголовков; логотип использует оформление главной страницы AYYY.
- Поиск, карточка задачи (примечания, ресурсы, предшественники, последователи).
- Сортировка задач внутри каждого уровня WBS без разрушения иерархии; переключаемые колонки задач (основные, ресурсы, базовые даты, критичность). Задачи доступны с клавиатуры (Enter/пробел — открыть сведения, Escape — закрыть).
- Навигация к текущему дню, указанной дате и выбранной задаче; вертикальные линии связей продолжаются через границы виртуального окна, для типов FF/SS/SF и задержек появляются подписи.
- Вкладка календарей проекта: рабочее время по дням, исключения/праздники и специальные недели. На Ганте можно включить подсветку нерабочих дней (без перепланирования).
- Анализ критичности: исходные флаги Microsoft Project при их наличии; иначе только явно обозначенная **приблизительная** самая длинная цепочка для простой сети FS без лагов. При циклах, ручном планировании и нетипичных связях вместо вымышленного результата выводится причина недоступности.
- Локальный экспорт диаграммы в SVG (не более 1000 отображаемых задач), пригодный для открытия, печати и сохранения в PDF через браузер.
- Таблица ресурсов (тип, группа, максимальная нагрузка, ставка, работа, стоимость) и отдельная таблица назначений (задача, ресурс, загрузка, даты, трудозатраты, стоимость). Поиск работает и по именам задач; для больших наборов показан безопасный лимит строк.
- Экспорт задач и назначений в два CSV с защитой от формул при открытии в табличных редакторах.
- Демонстрационный план с вымышленными данными; содержимое проекта не хранится в
  localStorage и сбрасывается при перезагрузке. В localStorage сохраняются **только настройки отображения** (масштаб, столбцы, сортировка, ширина таблицы и переключатели слоёв).
- Компактное оформление AYYY, адаптация для небольших экранов.
- Обработка файла в модульном Web Worker с резервным чтением в основном потоке, отменой предыдущей обработки при открытии нового файла.
- Ограничение количества одновременно отрисованных строк Ганта при больших планах; положение прокрутки сохраняется при перестроении диаграммы.

Никаких сетевых запросов с содержимым MPP нет. Сайт загружает собственный
модуль чтения из папки mpp/vendor; ссылки на сторонние проекты в
документации не используются как внешние сервисы обработки.

## Запуск

    python src/build.py
    python -m http.server 8000

Затем: http://localhost:8000/#mpp

Работает и как обычный статический сайт на GitHub Pages. GitHub Pages
по умолчанию публикует main, поэтому работа в отдельной ветке сама по
себе не меняет опубликованный портал.

## Тесты

    node --check mpp/model.mjs
    node --check mpp/viewer.mjs
    node --check mpp/reader-worker.mjs
    node --check src/mpp-route.js
    node --test tests/mpp_model.test.mjs
    python tests/mpp_build_test.py

Fixture: tests/fixtures/ayyy-project-sample.xml. Он вымышленный и может
быть открыт через интерфейс для проверки распознавания MSPDI.

CI дополнительно загружает и проверяет три открытых образца бинарных MPP разных поколений (MPP8/9/14), проверяет чтение бинарного MPP в Chrome и виртуализацию 2200 строк. Это smoke-проверка, а не полное сравнение всех полей с Microsoft Project. Для нестандартных календарей, длительностей и назначений обязательна сверка на реальных проектах.

    # Для полного браузерного сценария понадобятся playwright-core и Chrome
    CHROME_PATH=/path/to/chrome MPP_FIXTURES_DIR=/path/to/public-mpp-files node tests/mpp_browser_smoke.mjs

## Известные ограничения первого этапа

- Только чтение: нет редактирования или сохранения обратно в MPP.
- Линии связей между отображаемыми задачами пересекают границы виртуального окна, при этом задачи, скрытые сворачиванием иерархии или поиском, не создают линий. Задержки/опережения отмечаются текстом; базовый план строится по сохранённым в файле датам.
- Критические задачи выделяются по исходному признаку critical; если его нет, может отображаться **оценка самой длинной цепочки**, а не полноценный CPM. Рабочие календари и float извлекаются для просмотра, но **пересчёт расписания, ресурсное выравнивание и полноценный расчёт критического пути не реализованы**.
- Не все проприетарные поля и нестандартные календари MPP поддерживаются
  браузерным парсером. Защищённые паролем файлы могут не открыться. Вкладка календарей показывает распознанные записи, а не пересчитывает длительности.
- При ошибке чтения MPP пользователь может экспортировать Project XML
  в Microsoft Project и открыть его в этом же просмотрщике.
- Лимит размера выбранного файла: 40 МиБ. Крупные проекты обрабатываются в Worker, строки в Ганте виртуализуются. Производительность зависит от размера и сложности самого MPP, а не только от числа задач.
- Для длинных временных диапазонов Гант отображает не более 10 000 дней.
- Экспорт CSV для задач и назначений, SVG для отображаемой диаграммы. SVG ограничен 1000 строками и шириной 20 000 пикселей; для длинных планов используйте фильтрацию, сворачивание или CSV. Это **только просмотрщик**: редактор, запись MPP и интеграция с Jira не входят в текущую область работ.

## Архитектура

- src/mpp-route.js — регистрация AYYY-маршрута и загрузка JS/CSS.
- mpp/viewer.mjs — локальный выбор файла, таблицы, диаграмма, UI-события и виртуализация строк.
- mpp/reader-worker.mjs — изолированная обработка содержимого файла вне UI-потока.
- mpp/model.mjs — нормализация структуры, наследование календарей, сортировка WBS, анализ простой цепочки и построение зависимостей.
- mpp/export-svg.mjs — автономный экспорт диаграммы в SVG без внешних сервисов.
- mpp/style.css — оформление без зависимостей от UI-фреймворков.
- mpp/vendor/mpxj-ts/mpxj.mjs — независимый LGPL-парсер бинарного MPP.
- mpp/vendor/mpxj-ts/src — соответствующий TypeScript-код парсера.
- mpp/vendor/mpxj-ts/PROVENANCE.md — происхождение и сборка библиотеки.
