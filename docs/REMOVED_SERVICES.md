# AYYY — удаление пяти сервисов

Дата: 8 ноября 2026. Ветка: \`feat/weather-scene-themes\`.

## Удалено из исполняемого кода

По отмеченному пользователем скриншоту удалены:

1. **Почта** — Gmail OAuth, загрузка/отправка писем и локальные черновики.
2. **Мои посылки** — хранение трек-номеров и виджет 17TRACK.
3. **Мастерская** — редактор рисунков; при этом игры и генератор цветов сохранены.
4. **Заметки и задачи** — редактор заметок, список задач и связанные виджеты.
5. **Мои закладки** — каталог локальных закладок.

Удалены ссылки из бокового меню, записи реестра сервисов, маршруты и код
этих экранов. \`src/gmail.js\` удалён физически, остальные модули сокращены
до действующих функций. Удалены отдельные правила CSS для этих экранов и
переупакован \`index.html\` со свежими хешами ресурсов.

Число записей в реестре \`AYYY.services\`: **22 → 17**.
Значение возле «Все сервисы» задаётся из реестра при перерисовке страницы.

## Что сохранено

Главная, каталог, поиск, ИИ, погода (маяк и дерево), валюты и рынки,
инженерные инструменты, генератор паролей, палитра, игры и таймер фокуса.

Таймер фокуса отвязан от удалённого списка задач: теперь название занятия
вводится непосредственно в таймере. Сессии, статистика, звук, интервалы и
существовавшее описание сессии сохранены.

Избранное и ярлыки главной фильтруют ранее выбранные, но теперь удалённые
сервисы. Если все ярлыки были недоступны, предлагается актуальный набор.
Никакой очистки \`localStorage\` не выполняется: старые записи остаются в
браузере и включаются в полный экспорт JSON. Импорт через действующую форму
восстанавливает избранное и ярлыки главной; данные удалённых сервисов не
импортируются обратно в уже удалённые экраны.

## Проверки

- \`node --test tests/retired_services.test.cjs\` — регрессионные проверки
  каталога, маршрутов, оставшегося таймера/игр, устаревших ярлыков,
  поискового запроса, CSS и соответствия хешей всех ресурсов сборки.
- \`python src/build.py\` — формирование итогового \`index.html\`.
- Существующие тесты weather, markets, search и tools должны оставаться
  зелёными. Их код намеренно не менялся.

Статические проверки синтаксиса обновлённых JS/CSS и изолированная
проверка регистрации маршрутов пройдены. Полный браузерный прогон
(Chromium/Playwright) в этой сессии не выполнялся.
