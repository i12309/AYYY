# AYYY — атлас мыслей и компактная строка поиска

Дата: 8 ноября 2026 года. Ветка: `feat/weather-scene-themes`.

## Реализовано

- Вместо акварельной лупы `magnifier.webp` используется автономная статическая
  иллюстрация `assets/search/thought-atlas.svg` (820×1800). Это мозаика типичных
  запросов и интересов: книги, география, погода, видео, маршруты, музыка, фотографии,
  программирование, наука, здоровье, поездки, графики, рецепты, дом и идеи.
- Внутри композиции 26 разных векторных мотивов, 15 центральных сюжетов,
  90 миниатюр, карточки, тонкие связи, россыпь акварельных пятен и точек.
  Файл локальный, не требует CDN, шрифтов, внешних картинок или JavaScript.
- На desktop рисунок закреплён `position: fixed` относительно viewport,
  занимает `100svh`, пропорционально вписывается через `object-fit: cover`
  и плавно растворяется у правого края. Не перехватывает мышь или клавиатуру.
- На экранах не шире 720 px арт переходит в компактную декорацию заголовка.
- Уменьшены вертикальные интервалы между заголовком, строкой поиска и типами.
- `Google / Яндекс / DuckDuckGo / Bing` больше не карточки: компактные текстовые
  вкладки с тонкими цветными маркерами и подчёркиванием активной системы.
  У специальных типов поиска выбор провайдера по-прежнему отключён.
- Логика `mountSearch()`, запросы, сохранение провайдера и история не изменены.
  Действующие ссылки, горячие клавиши и кнопка «Найти» сохранены.
- Версии CSS/JS в `index.html` обновлены по SHA-256, чтобы не держался старый кэш.

## Изменённые файлы

`assets/search/thought-atlas.svg`, `src/search-page.css`, `src/search-page.js`,
`index.html`, `tests/search_browser.py`, `README.md`.

Старый `magnifier.webp` оставлен в репозитории для истории; поиск на него не ссылается.

## Проверки и ограничения

Статическая проверка изменений прошла: вложенность SVG-тегов, баланс CSS-скобок,
синтаксис JavaScript и актуальность версий ресурсов в `index.html`.

В `tests/search_browser.py` добавлены проверки загрузки SVG, отсутствия карточных
рамок у провайдеров, выбранного подчёркивания, `pointer-events: none`, правильного
режима `fixed/absolute` по ширине и неподвижности арта при прокрутке.

Полный прогон браузерного набора здесь **не выполнялся**: рабочее окружение не
имеет сетевого доступа для клонирования всего репозитория. Запуск в checkout:

```sh
python src/build.py
CHROMIUM_PATH=/usr/bin/chromium python tests/search_browser.py
SEARCH_VISUAL_OUTPUT=/tmp/ayyy-search CHROMIUM_PATH=/usr/bin/chromium python tests/search_browser.py
```

Проверяйте особенно 320×740, 390×844, 768×1024, 1024×768, 1440×900,
1920×1080 и 3840×2160, включая страницу с заполненной историей.
