# AYYY — чистая страница поиска без иллюстрации

Дата: 8 ноября 2026 года. Ветка: `feat/weather-scene-themes`.

## Что изменено

По запросу пользователя полностью удалён «атлас мыслей» из страницы поиска.
Удалён сам HTML-элемент изображения, а не только визуально скрыт через CSS.
Удалена двухколоночная сетка, из-за которой форма была сдвинута вправо;
убраны все классы и медиаправила фонового рисунка. На маршруте поиска
отключена фоновая декоративная текстура `.shore-page::before`.

В результате:

- Поисковая форма центрируется в рабочей области и занимает **100% доступной
  ширины с ограничением до 1440 CSS px** на крупных экранах (включая 4K).
- Строка ввода — на всю ширину контейнера, кнопка «Найти» справа.
- Типы поиска и выбор Google/Яндекс/DuckDuckGo/Bing расположены под строкой
  как компактные вкладки, без больших карточек.
- Разделы «Недавно искали» и «Нужен другой подход?» находятся на одной общей
  сетке, выровнены по краям формы; на телефоне идут друг под другом.
- Никакого фонового изображения нет ни на компьютере, ни на мобильном.
  Строка поиска, обработчики, история, хранилище и горячие клавиши сохранены.
- Старый SVG `assets/search/thought-atlas.svg` удалён из текущего дерева,
  но при необходимости доступен в истории Git.

## Файлы

`src/search-page.js`, `src/search-page.css`, `index.html`, `README.md`,
`tests/search_browser.py`; удалён `assets/search/thought-atlas.svg`.
Хеши CSS/JS в `index.html` изменены для обновления кэша.

## Проверка

Браузерные регрессионные тесты дополнены проверкой отсутствия фона и изображения,
полноширинной формы, выравнивания нижних разделов и адаптации для 320, 390,
768, 1024, 1440, 1920, 3840 CSS px. Старые проверки изображения удалены.

Статическая проверка JS/CSS и согласованности файлов пройдена. Полный
Chromium-набор требуется запустить из checkout репозитория:

```sh
python src/build.py
python tests/search_browser.py
```
