## Ограничения
Расчётная модель остаётся моделью планирования, а не графиком конкретного банка. На мобильном экране блоки располагаются в одну колонку — это осознанное решение для читаемости. Горизонтальная лента девяти инструментов прокручивается внутри себя. Декоративная панорама является локальным SVG без запросов к сторонним CDN.

## Коммиты
Контрольные точки: архитектурные рисунки, интеграция в оболочку, уплотнение ипотечного рабочего пространства, уплотнение инженерного и других инструментов, финальный QA.
