# HUMAN в AYYY: текущий объём работ

Цель — визуально и функционально приблизить модуль `AYYY/#health` к работающему HUMAN из `C:\CODE\human`, сохранив главную страницу портала и расположение логотипов. Работа выполняется в `main`.

## Условия

- Только статическая страница и браузерный JavaScript: GitHub Pages, без собственного сервера.
- Данные загружаются заново. Поддержка старых версий, конвертеры, миграции SQLite/ZIP HUMAN v1/v2 и обратный экспорт в них исключены пользователем.
- Поддерживается актуальная модель: новые записи, новые файлы и резервные копии текущего зашифрованного формата.
- IndexedDB содержит AES-GCM архив и несекретные метаданные; открытые данные и ключ существуют только в памяти разблокированного журнала.
- По выбору пользователя зашифрованный журнал синхронизируется в приватный GitHub. Для проверки разрешён `i12309/TEST_TREE`; `family-data/` не меняется.
- Не отправлять медицинские данные внешним ИИ или сервисам. Не выдумывать диагнозы, дозы, нормы, даты и отсутствующие значения.
