Ветка: `feat/weather-scene-themes`, исходная контрольная точка `61fc249`.
Работа находится в ветке задачи; публикация в основном GitHub Pages требует слияния PR.

## Что изменено

Дерево перенесено из утверждённого `AYYY_Weather_HTML_v5.html`. Эталон сохранён в `prototypes/weather-tree-v5/reference.html`, SHA-256 `4e7eb0cf62c3faf7606ea55b9bc5cbda2fb3d3ff7bf125df98d04cf6057dcc05`.
`tools/extract_weather_tree_assets.py` проверяет checksum, извлекает 11 PNG и адаптирует исходные palette/renderer. Для эталона отключено преобразование переводов строк в Git.

`scene-state.js` строит общие параметры из единого прогноза. Поддерживаются текущая погода, выбранный прогноз и зафиксированный ручной просмотр. WMO 97 классифицируется как гроза. Количество осадков нормализуется только при известных единицах мм и интервале; сила эффекта равна `min(1, sqrt(rate / 12))`. Старые данные без этих метаданных используют погодный пресет. Вероятность осадков не управляет интенсивностью.

`scene-controller.js` оставляет один активный renderer. Дерево загружается по запросу, до его готовности остаётся маяк. Идентификатор поколения отменяет устаревшие переключения. Подготовленная древесина и листва кэшируются один раз в памяти модуля. На смене времени не создаётся неограниченный кэш изображений.

Маяк использует прежние изображение, берег, море и CSS. Добавлены только параметры силы осадков, облачности и выключения вспышек. Байты `weather/assets/lighthouse.avif` не менялись.

Ручное управление находится в немодальном popover, который закрывается по Escape, внешнему клику, кнопке и при выборе города. Тема и настройки анимации сохраняются; ручные погода, месяц и время не сохраняются. Суточный цикл дерева запускается явно и останавливается при смене темы/прогнозного момента/города и выходе.

Сезон определяется по календарю города, для южного полушария художественный индекс сдвигается на 6 месяцев. В сухую зиму снег не включается только по месяцу. Месяц в ручном просмотре позволяет увидеть заснеженный зимний вариант. При отсутствующих или некорректных солнечных границах используется `isDay`, без демо-восхода.
