## GEDCOM — реализовано и проверено на синтетических данных

- [x] Браузерный парсер и экспортёр GEDCOM 5.5.1 и 7.x на TypeScript без Python в runtime.
- [x] Оригинал `original.ged` не меняется; записи `_raw`, неизвестные теги и метаданные остаются доступными при экспорте.
- [x] UTF-8, UTF-16, ASCII и CP1251 по явному выбору; ANSEL отклоняется без молчаливых замен.
- [x] Обычные биографии и ссылки на заметки, CONT/CONC, квалифицированные даты, несколько семей, усыновление, расширенный пол, имена с суффиксами и расширения.
- [x] 18 модульных тестов GEDCOM; браузерный smoke на импорт, экспорт, оригинал в ZIP и сохранение темы.
- [ ] Для полного соответствия Python GEN прогнать расширенный **дифференциальный** набор на одинаковых исходных .ged, сверить предупреждения и сериализацию неизвестных структур. Кодовая семантика в основном перенесена, но побайтовая идентичность экспорта не обещается.
- [ ] Профилировать импорт десятков тысяч персон, большие GEDCOM и стресс-тесты с фотографиями.

## Отложено: импорт резервного ZIP

Текущий экспорт ZIP нужен **не только на этапе миграции, но и постоянно**.
Это переносимый резервный архив между компьютерами, браузерами и версиями GEN.

Путь миграции: старый Python GEN → скачать полный `backup.zip` →
открыть AYYY/GEN → импортировать ZIP (включая `tree.json`, `original.ged`,
`tree.ged`, фотографии/PDF из `media/`) → сохранить локально в IndexedDB →
по желанию синхронизировать в личный приватный GitHub.

Обратный путь: AYYY/GEN → экспортировать полный ZIP → восстановить архив
в другом браузере или Python GEN при совместимости схем. В перспективе —
перенос из других программ через GEDCOM (не ZIP со случайной структурой).

- [ ] Импорт полного ZIP, проверка путей и ограничений объёма, проверка контрольных сумм.
- [ ] Восстановление `media/` без потери связей и `original.ged`.
- [ ] Импорт в новое дерево без перезаписи существующего ID.
- [ ] Тест полного цикла ZIP → новое устройство → повторный ZIP.
- [ ] Дать пользователю экспортировать архив независимо от GitHub.
