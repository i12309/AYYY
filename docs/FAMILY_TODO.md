## Резервные ZIP — реализовано, проверяется в CI

Текущий экспорт ZIP нужен **не только на этапе миграции, но и постоянно**.
Это переносимый резервный архив между компьютерами, браузерами и версиями GEN.

Путь миграции: старый Python GEN → скачать полный `backup.zip` →
открыть AYYY/GEN → импортировать ZIP (включая `tree.json`, `original.ged`,
`tree.ged`, фотографии/PDF из `media/`) → сохранить локально в IndexedDB →
по желанию синхронизировать в личный приватный GitHub.

Обратный путь: AYYY/GEN → экспортировать полный ZIP → восстановить архив
в другом браузере или Python GEN при совместимости схем. В перспективе —
перенос из других программ через GEDCOM (не ZIP со случайной структурой).

- [x] Импорт ZIP из Python GEN (DEFLATE) и браузерного GEN (STORE), проверка безопасных путей, размера и CRC32.
- [x] Восстановление `media/`, фотографий, PDF и точных байтов `original.ged` одной IndexedDB-транзакцией.
- [x] Импорт отдельной копии дерева; конфликты ID и slug разрешаются новым именем каталога без изменения родственников.
- [x] Проверки ZIP → IndexedDB → экспорт → повторный ZIP, Python DEFLATE и отклонение небезопасных архивов.
- [x] ZIP экспортируется без GitHub в любой момент.

Ограничения: ZIP до 150 МБ, файлы до 60 МБ, до 3000 записей и 350 МБ распакованных данных. ZIP64 и зашифрованные архивы не поддерживаются.
