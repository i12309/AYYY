## Отложено: импорт резервного ZIP

Текущий экспорт ZIP нужен **не только на этапе миграции, но и постоянно**.
Это переносимый резервный архив между компьютерами, браузерами и версиями GEN.

Путь миграции: старый Python GEN → скачать полный `backup.zip` →
открыть AYYY/GEN → импортировать ZIP (включая `tree.json`, `original.ged`,
`tree.ged`, фотографии/PDF из `media/`) → сохранить локально в IndexedDB →
по желанию синхронизировать в личный приватный GitHub.

Обратный путь: AYYY/GEN → экспортировать полный ZIP → восстановить архив
в другом браузере или Python GEN при совместимости схем. В перспективе —
перенос из других программ через GEDCOM (не ZIP со случайной структурой).

- [ ] Импорт полного ZIP, проверка путей и ограничений объёма, проверка контрольных сумм.
- [ ] Восстановление `media/` без потери связей и `original.ged`.
- [ ] Импорт в новое дерево без перезаписи существующего ID.
- [ ] Тест полного цикла ZIP → новое устройство → повторный ZIP.
- [ ] Дать пользователю экспортировать архив независимо от GitHub.

**Пока этот пункт не реализуем**, существующий экспорт ZIP оставляем.
