## Выполнено

Маршрут `#weather` заменяет прежнюю страницу новой сценой. Адаптер включён перед `boot.js`.
Главная и каталог остаются прежними. Страница `weather/` также работает отдельно.
Сборка в другую папку копирует все зависимости, включая weather/ и прозрачный AVIF маяка.
Корневой HTML содержит версионированные ссылки на локальные модули; `--inline` сохранён.

Маяк не заключён в карточку. Добавлен непрерывный скалистый берег на всю ширину,
с изменением освещения и палитры. Доработан контраст подписей, убрано обрезание седьмого дня;
почасовой график размещён между числовыми значениями и вероятностями осадков, не поверх них.
Композиция является HTML/SVG/Canvas, не картинкой с приклеенными кнопками.

Выбор города, обновление, 7/14 дней, выбор часа, графики, единицы, визуальные пресеты, пауза,
уменьшенное движение, кэш и возвращение к главной проверены на браузерном стенде.
После перехода из погоды её таймер и requestAnimationFrame освобождаются.
Ошибка загрузки отдельного ресурса показывает повтор, после повтора страница восстанавливается.

## Осознанные ограничения

Море, берег, птицы и луна — художественная визуализация, не данные морского прогноза или фаза Луны.
При первом открытии реальные данные запрашиваются по «Обновить»/выбору города, не автоматически.
Состояния сцены из меню не меняют показания и отмечены как предпросмотр.
При недоступности API остаются последние сохранённые данные либо явно подписанный пример.

Внешние библиотеки и новый backend для сцены не добавлялись; остальные интеграции не изменялись.
