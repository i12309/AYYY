## Осознанные ограничения

Море, берег, птицы и луна — художественная визуализация, не данные морского прогноза или фаза Луны.
При первом открытии реальные данные запрашиваются по «Обновить»/выбору города, не автоматически.
Состояния сцены из меню не меняют показания и отмечены как предпросмотр.
При недоступности API остаются последние сохранённые данные либо явно подписанный пример.

Внешние библиотеки и новый backend для сцены не добавлялись; остальные интеграции не изменялись.


## Резервное подключение через corsproxy.io

Для демонстрационного проекта владелец разрешил публикацию общего ключа corsproxy.io: он встроен в `weather/model.js`. Ввод и локальное сохранение ключа не требуются. Форма ввода удалена; резервное подключение доступно всем посетителям, в том числе при запрещённом localStorage. Старые локальные значения ключа не используются.

Запрос сначала выполняется напрямую (до 3,5 секунды), затем при сетевой ошибке или HTTP 5xx — через corsproxy.io (до 10 секунд). Весь исходный URL кодируется через URLSearchParams. Прокси получает координаты выбранного города или строку поиска города; cookies не отправляются. Для проверки разрешённого домена передаётся только origin сайта. HTTP 4xx, включая 429, и отмена пользователем не запускают обходной запрос. Ошибки обоих соединений сохраняют предыдущий прогноз.

Модель данных теперь общая с первого открытия главной: обновление там сохраняет полный прогноз, а переход на страницу погоды сохраняет выбранный город. Декорации загружаются по-прежнему при открытии погоды, внешних автоматических запросов на главной не добавлено.

Проверки: 34 теста модели, 11 тестов транспорта (`node tests/weather_proxy.test.cjs`, предварительно `node tests/model.test.cjs --fixture`), 8 тестов сборки. Реальный браузерный запрос через предоставленный пользователем ключ вернул HTTP 200, 14 дней и 336 часов. Полный сценарий прямой тайм-аут → прокси → обновление интерфейса занял около 5 секунд. Проверены резервный запрос без ввода ключа, работа при недоступном хранилище и отсутствие формы ввода. Общий ключ публичный по решению владельца демо.
