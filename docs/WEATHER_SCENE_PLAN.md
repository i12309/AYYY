# Погода AYYY — единая живая сцена

## Задача
Перенести утверждённый макет в действующий портал, не превращая маяк в отдельную карточку. Маяк занимает центральную часть экрана по высоте; берег, вода и небо продолжаются от края до края. Слева — текущие условия, справа — прогноз, внизу — почасовая лента. Интерфейс является частью пейзажа, без прямоугольных границ сцены.

## Этапы и контрольные точки
1. Сохранить рабочий план в main (этот коммит).
2. Добавить модули погоды, атмосферную сцену и адаптивную компоновку; сохранить отдельным коммитом.
3. Подключить маршрут #weather и сборку, проверить взаимодействия и сохранность остальных сервисов.
4. Проверить дневную/ночную погоду, осадки, снижение движения, мобильный экран и источник данных; сохранить результаты.

## Ограничения
- Статические HTML/CSS/JS, совместимые с GitHub Pages, без собственного backend.
- Никаких ключей и пользовательских данных в репозитории.
- Демонстрационные данные явно отделены от прогноза Open-Meteo; предпросмотр сцены не подменяет числовые данные.
- Исходная акварельная стилистика; панорамная береговая линия без рамки.
- Анимации приостанавливаются в скрытой вкладке, учитывают prefers-reduced-motion; все обработчики удаляются при смене маршрута.

Исходная база: main 9d77397. Для модели данных используется ранее подготовленный пользователю пакет AYYY_weather_package.zip; визуальная композиция перерабатывается под последний утверждённый макет.
