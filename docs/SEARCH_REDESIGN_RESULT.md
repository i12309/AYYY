# Поиск AYYY — соответствие визуальному референсу

Обновлён маршрут `#search` и автономный HTML-макет. Приоритет композиции — приложенное изображение 1672 × 941, а не исходные мелкие шрифты прототипа. Работа выполнена в `main` по прямому указанию пользователя; отдельная ветка и PR из общего задания не создавались.

## Результат

- Заголовок и подзаголовок увеличены и выровнены по левой направляющей.
- Поиск расположен на 21,53% ширины страницы, занимает 57%; высота строки — 48 px. На референсной ширине положение отличается от изображения менее чем на 8 px.
- Восстановлены интервалы между поиском, режимами, провайдерами, пояснением и нижними панелями. Соотношение ширины панелей — 1,26:1.
- Убраны лишние надзаголовки, счётчики и подсказки клавиш из визуальной композиции; реальные клавиатурные команды сохранены.
- Использованы отдельные локальные иллюстрации лупы и монитора. Скриншот целиком не используется как фон. Графика не перехватывает клики.
- На мобильных провайдеры расположены 2×2, панели — вертикально, режимы прокручиваются внутри строки.
- Сохранены `AYYY.performSearch`, существующие ключи истории и поисковика, внешние результаты, экранирование запросов и общий Ctrl/Cmd+K.
- В production нет демонстрационной истории. Автономный прототип сохраняет свои демонстрационные данные отдельно.

Хеши текстовых ресурсов и переводы строк сборки нормализованы: одинаковые исходники дают одинаковый `index.html` на Windows и Linux. Изменения погоды из предыдущей задачи не включены в коммиты поиска.

## Ограничения

Расположение и размеры интерфейсных блоков приближены к изображению. Акварельная фактура, дополнительные мелкие рисунки и растения не воспроизведены пиксель в пиксель: использованы предоставленные отдельные изображения и SVG-декор. Поисковая выдача открывается в новой вкладке внешнего сервиса. Работа внешних поисковиков и погодного API не гарантируется этими локальными тестами.
