# Инструменты AYYY — исправление соответствия утверждённому макету

6 ноября 2026. Исходная версия: `6adbae4`.

## Что было исправлено

Предыдущая реализация не соответствовала согласованной композиции: вместо акварельного здания использовался упрощённый SVG, текст был чрезмерно мелким, график и структура затрат выглядели как одна растянутая панель, отсутствовал нижний ряд сценариев и краткого резюме.

Новая версия использует декоративную живопись из утверждённого пользователем изображения: башню, верхнее небо и нижний городской горизонт. Подписи, цифры, кнопки и формы из рисунка исключены. Файл `tools/assets/approved-city-frame.avif` содержит только оформление с пустой центральной областью. Поля, графики и все финансовые значения остаются настоящими HTML/SVG, а не картинкой с невидимыми кнопками.

Восстановлены раздельные карточки графика и структуры затрат, четыре показателя сверху, сценарии и резюме снизу. Сохранён полный редактор досрочных взносов, ставок и графика платежей. Панели остаются компактными, но основной ввод — 13 px на desktop, показатели — 23–28 px. Ключевые блоки укладываются в первый экран 1600×900. Мобильная версия перестраивается в одну колонку.

## Поведение

- Используются исходные элементы форм: без дублирования полей и обработчиков.
- Денежные значения отображаются с разделителями тысяч; при фокусе доступен исходный числовой ввод.
- Сценарии и резюме рассчитываются через существующий `AYYYLoans`; значения макета не подставляются.
- Подсказки графика используют строки действительного расчётного графика.
- Сравнение не смешивает сценарии в разных валютах.
- При ошибке локального сохранения несовпадающие дополнительные показатели скрываются, а основные вычисления продолжают работать.
- При смене маршрута адаптер освобождает наблюдатель и обработчики.
- `loan-model.js` и `science-model.js` не изменены. Нового backend или сетевой отправки финансовых данных нет.
